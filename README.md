# 🔥 Généraeur MDP Dubaï V2

**Mon générateur de mots de passz Python - Jour 4 à 15 ans**

### ⚡ C'est quoi ?
Script Python qui génère des mots de passe sécurisés.
Tu choisis la longueur, la quantité, etsi tu veux des symboles `!@#$%^&*`.

### 🚀 Comment lancer le projet
1. Télécharge `generateur.py`
2. Ouvre un terminal et lance : `python generateur.py`
3. réponds aux 3 questions
4. récupère tes MDP
